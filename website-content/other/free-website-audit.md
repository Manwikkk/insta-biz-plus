## 13 critical SEO & performance checks in one report

More than a Lighthouse score. Each check is manually reviewed by a senior engineer with concrete fixes you can ship today, including the latest 2026 signals like INP, AI Overviews and Generative Engine Optimization.

Core Web Vitals

INP, LCP, CLS and TTFB scores from real-world Chrome user data (CrUX).

Technical & On-Page SEO

Title tags, meta descriptions, heading structure, canonical tags and schema markup.

AI Search Visibility (GEO)

ChatGPT, Perplexity, Google AI Overviews citation readiness and llms.txt review.

Mobile UX & Responsiveness

Touch targets, viewport, responsive layout and readability on real devices.

Security & SSL

HTTPS, security headers, mixed content and common vulnerabilities.

Conversion Rate Audit

Hero clarity, CTA strength, form friction and trust signals (CRO).

Accessibility (WCAG 2.2)

Alt text, colour contrast, keyboard navigation and screen reader gaps.

Code Quality

Bloated JavaScript, render-blocking resources, broken links and console errors.

Traffic & Behaviour Insights

Where visitors come from, drop-off pages and engagement signals.

Information Architecture

Site structure, navigation depth, internal linking and crawl budget efficiency.

Competitor Benchmark

How you stack up against 2 to 3 closest competitors on speed, SEO and content.

Backlink Profile

Domain authority, referring domains, toxic links and link-building gaps.

Prioritised Action Plan

Quick wins first, then long-term fixes ranked by impact and effort.
